DaVinci Resolve Compat 1.4.0

Requires an Apple silicon Mac running macOS 12 or later.
Python is included.

1. Drag the app into Applications and open it.
2. Use Language in the menu bar to choose English or Simplified Chinese.
3. Select a .drp or .dra project and choose the target Resolve version.
4. Create a compatibility copy and import it in the target version.

This build is ad hoc signed and has not been notarized.
For macOS first-open guidance, see https://support.apple.com/en-us/102445.

The app patches project version markers. Check the generated copy in
Resolve before relying on it. For archived media, relink MediaFiles
from the original archive if necessary.
