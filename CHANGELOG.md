# Changelog

## 1.3.3

Initial public source release of the existing desktop tool.

- Automatic or manual Resolve 19 / 20 target selection.
- Default output next to the source, with numbered GUI filenames.
- Pinned, bundled Python runtime for Apple Silicon.
- DMG background scaling and hidden resource layout fixes.
- Generic conversion button with a separate resolved target indicator.
- Jzero copyright notice in the About dialog.
- Runtime download, checksum verification, build instructions and converter tests.

Runtime validation is limited to the samples described in README.
